Rile app icon concepts

Eight directions on the macOS Big Sur+ grid (1024 canvas, 824 rounded-square body, 100 px margin, soft drop shadow). Each is shown at 512, 128, 64 and 32 px on light and dark backgrounds. Colors are taken from the Native chrome: graphite #202022–#3a3a3e, accent #6296cf → #3f72aa, highlight #9fc8f4.

Once one is picked, export it to .icns: render PNGs at 16, 32, 64, 128, 256, 512, 1024 (e.g. rsvg-convert -w N icon-X.svg) into Rile.iconset/ with the icon_NxN.png / icon_NxN@2x.png names, then run iconutil -c icns Rile.iconset.

Monogram Folder

icon-1.svg

A classic blue folder carrying a bold rounded R on graphite. Reads instantly as a file manager and as Rile.

02

Bolt Folder

icon-2.svg

A white folder struck by an amber bolt with speed lines. Puts speed first, which is the main selling point.

03

Card Stack

icon-3.svg

Fanned file cards in accent blue, graphite and paper on a light silver tile. About the files more than the folders.

04

Rill

icon-4.svg

Three flowing bands, Rile as in rill: files moving smoothly. The most abstract choice, and still legible at 32 px.

05

Compass Rose

icon-5.svg

A faceted eight-point rose with a blue north point on deep navy. Explorer as navigation, without imitating Safari's dial.

06

Miller Panes

icon-6.svg

A graphite Rile window whose blue selections step across three columns. Shows the column and dual-pane navigation.

07

Seek

icon-7.svg

A magnifier over a folder on indigo. Says fast search; the cooler hue stands apart from Finder blue in the Dock.

08

Glyph

icon-8.svg

A geometric R built from a white stem, a blue tab-like bowl and a slanted leg. Minimal, ownable, and sharp when small.
