# Approved Overview artwork

These original vector assets match the Native Overview prototype. They are exported from `mockups/overview-art.js` for reuse by the native app; each is a standalone 64 × 64 SVG with its own gradient IDs. The files are decorative, so the app should provide accessible labels on the adjacent metric or device text rather than on the artwork itself.

| Asset | Intended use |
| --- | --- |
| `storage.svg` | Storage-used metric |
| `files.svg` | Discovered-files metric |
| `folder.svg` | Folders metric |
| `computer.svg` | Connected-disks metric or internal computer |
| `external-drive.svg` | External storage device |
