# Native application screenshots

The `native-*.png` images linked from the main README were captured from the
running Rile v0.6.0 macOS application on 2026-10-28, in dark mode with a blue
accent. They are not browser mockups.

The capture session used a separate `RILE_CONFIG_DIR` and an illustrative
`/tmp/Rile Showcase/Studio` folder. Its documents, generated landscape artwork,
and storage-analysis sample files are demonstration content. The Backups image
shows an actual completed local backup of that content. Device names, storage
totals, and Home statistics are live values from the capture machine.

Capture only the app window, without its desktop or window shadow, using
macOS `screencapture -x -o -l <window-id> <image.png>`. The published images are
resized to 1600 pixels wide and PNG-optimized; no interface elements or values
have been composited into them.

For future updates, use sample files and isolated settings rather than personal
documents. Disable automatic photo descriptions for the capture session, finish
or cancel background jobs, dismiss notifications, and move the pointer away
before capturing. Review each image for private information and confirm that
README captions describe the visible state.
